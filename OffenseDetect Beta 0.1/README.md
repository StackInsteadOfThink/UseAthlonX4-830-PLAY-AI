# 脏话 + 种族歧视检测（细分版）

比"毒舌"更细的检测器：**一个模型判"是不是脏话"，另一个模型判"歧视的是哪种人"**（无 / 白种人 / 黄种人 / 黑种人）。中英文各一组，共 4 个模型，在速龙 X4 830（纯 CPU）上训练。

## 文件都是干嘛的

| 文件 | 作用 |
|---|---|
| `menu.bat` | **启动器，双击这个就行** |
| `build_data.py` | 构建训练语料（脏话库 + 歧视语料，中英文各一套）|
| `train.py` | 训练 4 个模型 |
| `predict.py` | 输入文本，同时输出"是否脏话"和"歧视对象"两个判定 |
| `bench.py` | 性能测试脚本 |
| `abuse_zh.npz` / `abuse_en.npz` | 中文 / 英文"脏话与否"模型 |
| `discr_zh.npz` / `discr_en.npz` | 中文 / 英文"歧视对象"模型 |
| `abuse_zh.npy` / `abuse_en.npy` 等 | 对应语料数据（.npy）|

## 怎么用

1. 双击 `menu.bat`。
2. 选 **2 检测** → 输入文本（中英文均可），自动判"脏话 + 歧视对象"，输入 0 退出。
3. 想重新训练：选 **1**（训练 4 个模型）。

示例输入 `you nigger.` → 会判"脏话"且"歧视黑种人"。

## 注意

- 两个判定是分开的模型，各自独立。
- `menu.bat` 里写死了 `D:\OffenseDetect Beta 0.1` 路径，解压到别处要先改开头的 `cd /d`。
- 需要 Python 3.12 + numpy。
