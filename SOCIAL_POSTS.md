# ATHLON X4 830 AI Experiment Series

This repo is a compact portfolio of small AI experiments built on a **2015 AMD Athlon X4 830** using **pure NumPy** and **CPU-only** training.

## Why this project matters

The core story is simple: on a low-end desktop CPU, with no GPU and no deep learning framework, it is still possible to train, test, and run lightweight AI models.

This project includes:
- CIFAR-10 image classification
- Chinese / English sentiment analysis
- OCR digit recognition
- Q-learning experiments
- TicTacToe AI
- Toxicity / offense detection demos

## Project positioning

- This is a hobby, research, and learning project.
- The focus is on old-hardware AI feasibility and educational experimentation.
- It is not a production-grade or large-scale commercial model.
- It is best used for demo, study, prototyping, and curiosity-driven exploration.
