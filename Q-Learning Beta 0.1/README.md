# Q-Learning 走迷宫

在速龙 X4 830（纯 CPU，不用显卡）上训练的强化学习小项目：AI 用 **Q-learning** 算法自己在迷宫里反复试错，学会从入口走到出口。

## 文件都是干嘛的

| 文件 | 作用 |
|---|---|
| `menu.bat` | **启动器，双击这个就行**，不用管其他脚本 |
| `maze.py` | 迷宫核心代码（生成、打印、行走逻辑）|
| `maze_gen.py` | 生成迷宫地形，存成 `.q` 文件 |
| `qlearning_train.py` | 训练 AI，把经验存成 `.npz` 权重 |
| `qlearning_play.py` | 让训练好的 AI 走迷宫，打印出路径 |
| `diag.py` | 调试辅助脚本，一般用不上 |
| `Q_20x20.q` / `Q_20x20.npz` | 现成 **20×20** 迷宫的地形 + 训练好的权重（约 70 步走出）|
| `Q_5x5.q` / `Q_5x5.npz` | 现成 **5×5** 迷宫的地形 + 权重（16 步走出）|

## 怎么用

1. 双击 `menu.bat`。
2. 选 **1 生成迷宫** → 输入尺寸（如 5 / 12 / 20），生成新的 `.q` 地形文件。
3. 选 **2 训练** → 输入尺寸和轮数（如 2000 / 30000 / 1000000），训练出 `.npz` 权重。
4. 选 **3 推理** → 输入迷宫文件名和权重文件名，看 AI 走迷宫。

**不想自己训练**：直接选 **3**，输入现成的 `Q_20x20.q` 和 `Q_20x20.npz` 就能看效果。

## 注意

- `.q` = 迷宫地形，`.npz` = AI 权重，**别搞混**。
- `menu.bat` 里写死了 `D:\Q-Learning Beta 0.1` 这个路径，如果解压到别的位置，要先改它开头的 `cd /d` 一行。
- 需要 Python 3.12 + numpy。
