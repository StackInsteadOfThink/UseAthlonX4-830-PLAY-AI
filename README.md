# 🐎 用速龙 X4 830 玩 AI —— 纯 numpy 从零训练 CIFAR-10 图像分类

> 用一颗 **2015 年的 AMD Athlon X4 830**（没有 AVX2、没有 GPU 加速）跑出来的图像分类模型。
> 全程只用 **纯 numpy**，手写卷积、池化、反向传播，从 0 训出一个能认图的 CNN。

### 🧠 那 `.npz` 到底是什么？

`.npz` 是 **numpy 的压缩存档格式**（Numpy Compressed Archive），专门用来把多个数值数组打包成一个文件，还能自动压缩变小。

`cifar_model_v2.npz` 里面装的是训练出来的 **8 个数组**：

```
W1/b1  →  第一层卷积的权重 + 偏置
W2/b2  →  第二层卷积的权重 + 偏置
W3/b3  →  第一层全连接的权重 + 偏置
W4/b4  →  第二层全连接的权重 + 偏置
```

总共 **268,650 个参数**，用 float32（4 字节/个）存 → 约 1MB。
通俗说：**训练就是在不断调整这 26.9 万个数字，直到它们"认得" 10 类物体**。`.npz` 就是这些数字的存档。

## 🚀 使用（傻瓜版）

> 打开命令提示符：按 **Win + R**，输入 `cmd`，回车。
> 下面分三类：**①必做准备**、**②日常推理**、**③可选训练**。

### ① 必做准备（只需一次）

**装依赖（如果电脑上没有 NumPy 和 Pillow 库，用 pip 装）**
```
python -m pip install numpy pillow
```
> 💡 如果运行时报 `No module named 'numpy'` 或 `No module named 'PIL'`，
> 说明电脑缺少这两个库，用上面这条 pip 命令装上即可再运行。

**下载数据（约 170MB）**
```
python download_data.py
```

### ② 日常使用 · 识别一张图（★最常用）

```
python cifar_predict.py 图片路径
```
把图片文件**直接拖进**命令窗口，回车。或写全路径：
```
python cifar_predict.py D:\照片\猫.jpg
```
输出示例：
```
识别为: 猫  (置信度 62.2%)
--- 各类别概率 ---
  飞机: 0.7%  汽车: 0.1%  鸟: 0.3%
  猫: 62.2%  鹿: 0.3%  狗: 36.0%  ...
```

### ③ 可选 · 自己训练模型（想直接推理就跳过这步）

```
python cifar_cnn_v2.py 20
```
仓库已附赠训练好的 `cifar_model_v2.npz`，**如果你想直接推理，可以忽略这步**，直接用现成模型就行。想自己重新训练再跑这条。

## 💡 经验与心得

1. **没有 AVX2，也别放弃训练**——numpy 手写照样能训，只是慢。这颗速龙证明：老 CPU 也能从 0 跑出图像分类。
2. **数据增强真的很值**——加了水平翻转，准确率从 67% 提到 71.6%，泛化明显变好，还不花训练时间。
3. **低分辨率是硬瓶颈**——32×32 输入下，鸟/鹿/青蛙这类轮廓相似的类天然容易混，不是训练不够，是输入信息量就这么多。
4. **模型可以小到出乎意料**——26.9 万个参数就够认 10 类。大模型大，是因为要学的多；小任务，小网络就是最优解。
5. **手写反向传播要小心池化层**——池化反向要"一块均分回传"，形状没对齐直接崩。踩过的坑都是学费。
