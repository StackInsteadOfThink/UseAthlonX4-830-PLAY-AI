# 毒舌 / 种族歧视检测

判断一句话属于三类之一：**正常 / 脏话 / 种族歧视**。中英文都支持，在速龙 X4 830（纯 CPU）上训练。

## 文件都是干嘛的

| 文件 | 作用 |
|---|---|
| `menu.bat` | **启动器，双击这个就行** |
| `build_data.py` | 构建训练语料（正常/脏话/歧视三类，中英文各一套）|
| `train.py` | 训练中英文检测模型 |
| `predict.py` | 输入一句话，给出三类概率 |
| `bench.py` | 性能测试脚本 |
| `model_zh.npz` / `model_en.npz` | 中文 / 英文模型权重 |
| `train_zh.npy` / `train_en.npy` | 训练用的语料数据 |

## 怎么用

1. 双击 `menu.bat`。
2. 选 **2 检测一句话** → 输入中英文均可，输入 0 退出。
3. 想重新训练：选 **1**。

示例输入 `你是一个香蕉` → 会判为"歧视"。

## 注意

- 一句话可能同时踩多条线，结果给的是三类概率，取最高的一项。
- 个别有歧义的批评句（如"你这人素质真差"）可能判不准，这是三分类的固有局限。
- `menu.bat` 里写死了 `D:\ToxicDetection Beta 0.1` 路径，解压到别处要先改开头的 `cd /d`。
- 需要 Python 3.12 + numpy。
